VIPBangla999 Android Demo Project

এই প্রজেক্টটি একটি non-monetary demo app।
এতে বাস্তব টাকা দিয়ে বাজি, deposit, withdrawal বা cash prize নেই।
শুধু virtual/demo interaction আছে।

APK তৈরির সহজ পদ্ধতি (Android ফোন থেকেও):
1. ZIP ফাইলটি Extract করুন।
2. GitHub-এ নতুন repository খুলুন।
3. Extract করা ফোল্ডারের ভেতরের সব ফাইল repository-তে upload করুন।
4. GitHub repository > Actions খুলুন।
5. 'Build VIPBangla999 Demo APK' workflow নির্বাচন করে Run workflow চাপুন।
6. Build শেষ হলে workflow run-এর নিচের Artifacts থেকে VIPBangla999-Demo-APK ডাউনলোড করুন।
7. ZIP extract করে app-debug.apk ফোনে install করুন।

Build-এর জন্য Java 17 ও Gradle 8.9 workflow-তে স্বয়ংক্রিয়ভাবে সেট করা আছে।
